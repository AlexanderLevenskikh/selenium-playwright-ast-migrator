# Selenium Playwright Migrator — v0.0.4-preview.1

### Added

- New experimental `--mode config-source`: each adapter-config source-side key
  (methods, parameterized methods, page objects, tables, pagination, navigation URLs,
  suppressions/scaffold, scopes, generic-result methods, source-only identifiers) is
  located in the actual Selenium source and reported as used/unused with a coverage %
  and the first occurrence `file:line`. The same report (`config-source.json` + `.md`)
  is now also emitted additively into `analyze`, `migrate`, and `run` report
  directories. Report-only — it never edits the config or the source.
- Honest conversion metrics: reports now expose `GeneratedTests` and
  `FullyConvertedTests` computed via `ExecutableTargetSemantics` (a test counts as fully
  converted only when every action, including shared setup, is provably emitted as
  executable target code with no TODOs), plus a flattened
  `TotalActions`/`StructuralContainers` accounting invariant. The old
  `SuccessfullyConvertedTests` ("no UnsupportedAction") is kept but its blind spot is now
  visible.
- Determinism harness: `run --twice --assert-identical` rebuilds the pipeline twice into
  `run-a/`/`run-b/` and compares byte-level `RunDigest` digests (canonical JSON; only
  `generatedAtUtc`/`generatedAt` wall-clock fields excluded). Non-identical output fails
  with exit code 6 (`RUN_DETERMINISM_ASSERTION_FAILED`).

### Changed

- Inline `WebDriver.FindElement(...)` action targets now resolve to the same single
  `Page.Locator` as declaration reuse (LOC-01), consistently across
  `By.Id` / `By.CssSelector` / `By.XPath`.
- Product-state waits whose direction is inferred from the method name are no longer
  emitted as silent guesses: unproven directions surface as `ReviewRequired` so the
  hudstate/wait mapping is decided from product evidence, not by name alone.

### Fixed

- `verify-project` now counts `RawExpression` targets and elided locator null-checks as
  executable, so a syntactically-valid generated test that preserves behavior is not
  misreported as losing its assertion.
- Coverage: the stable corpus grew to 36 vertical-slice fixtures, including
  cross-project async-lift caller (multi-project, `ProjectReference`) and explicit
  broken-source/stale-repattern/adversarial gap fixtures; reserved-as-design behaviour
  (broken source, unsupported browser contexts, helper-dependent unmapped calls) fails
  closed and is documented in the semantic-accounting ledger with `invariantHolds=True`.

### Remaining experimental

- `config-source`, `explain-todo`, `migration-board`, and `helper-inventory` modes stay
  experimental and may change without notice.
