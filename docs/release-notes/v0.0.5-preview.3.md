# Selenium Playwright Migrator — v0.0.5-preview.3

### Fixed

- `templates/migration-kit/scripts/update-autonomy-state.ps1` now stores the
  recorded cycle's `completedAtUtc` as a whole-second UTC string
  (`yyyy-MM-ddTHH:mm:ssZ`) instead of the ISO-8601 round-trip form. PowerShell 7
  coerces ISO date strings to `System.DateTime` in `ConvertFrom-Json` and
  `ConvertTo-Json` re-serializes them with trailing fractional zeros trimmed
  (e.g. `2026-10-06T21:05:26.0461560Z` becomes `2026-10-06T21:05:26.046156Z`).
  Those two forms are semantically equal but hash differently, so the
  ledger-anchored canonical state hash drifted between the action that recorded a
  cycle and the next invocation that re-read the state. When the last fractional
  digit was `0` (roughly one in ten timestamps) the next invocation failed with
  `AUTONOMY_STATE_LEDGER_MISMATCH`, which surfaced as a flaky
  `Mig06_NewInvocationPreservesCumulativeCycleProof` on CI. The whole-second form
  is byte-invariant under the JSON round trip in both PowerShell 7 and Windows
  PowerShell 5.1.

### Added

- `Mig05_RecordedCycleTimestamp_IsWholeSecondRoundTripInvariant` locks the
  `completedAtUtc` format so the state hash cannot drift again.

### Notes

- The flake was reproduced locally (roughly one failure in twelve
  `update-autonomy-state` invocations) and this release is verified with a
  40-iteration stress run of the affected scenario plus a 30-run loop of
  `Mig06_NewInvocationPreservesCumulativeCycleProof` — zero failures.
