# `/supervised-task`

| Команда | Поведение |
|---|---|
| `/supervised-task` | Запустить или возобновить полный настроенный scope и выполнить до пяти автономных циклов исправлений. |
| `/supervised-task continue` | Продолжить по последним evidence с новым бюджетом в пять циклов; исчерпанные кандидаты не повторяются без новых данных. |
| `/supervised-task continuous` | Автоматически переходить через контрольные точки по пять циклов до успеха или настоящей обязательной остановки; повторно вызывать `continue` не нужно. |
| `/supervised-task continue continuous` | Явное непрерывное продолжение с теми же правилами циклов. |
| `/supervised-task <ограниченный запрос>` | Выполнить запрошенный цикл; `continuous` разрешает затем перейти к другим безопасным кандидатам. |

Одно ограниченное изменение разрешено на цикл, а не на весь вызов. Прогресс сбрасывает счётчик no-progress. После первого безрезультатного цикла выбирается другой независимый кандидат; остановка происходит после двух подряд разных безрезультатных кандидатов. Ошибка project verification учитывается отдельно и блокирует остальную работу только тогда, когда мешает честно измерить любой оставшийся кандидат.
